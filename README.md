# OXNULL // Defying Gravity, Securing Cyberspace

An interactive, futuristic cybersecurity club website with an overarching anti-gravity / zero-gravity physics theme, built for **Malla Reddy College of Engineering & Technology (MRCET) Cybersecurity Club**.

---

## ✨ Features

- **Zero-Gravity Physics Engine:** Canvas-driven weightless particle field, gravitational cursor repulsion, and global click shockwaves that repel floating UI elements.
- **Synthesized Cyber Audio:** Pure browser Web Audio API sound designer for sub-bass shockwaves and interactive audio cues.
- **The 7 Tactical Domains:**
  1. **Awareness** — Baseline cyber hygiene & social engineering vectors.
  2. **Explore** — Foundational labs, beginner CTF sandboxes & Linux basics.
  3. **Blue Team & Red Team** — Adversary emulation vs active kinetic defense.
  4. **Digital Forensics** — Volatile RAM analysis & artifact carving.
  5. **Cryptography** — Classical ciphers to post-quantum algorithms.
  6. **Cloud Security** — AWS/GCP/Azure hardening & container runtime defense.
  7. **Security Architecture** — Zero Trust architecture & STRIDE threat modeling.
- **Mission Trajectory:** Orbital radar and calibration telemetry.
- **Interactive Controls:** Zero-G physics stabilization toggle (reduced-motion accessibility), sound FX toggle, and Gravity Inverter mode.

---

## 🚀 Running Locally

You can serve the static site using Python or any static HTTP server:

```bash
# Using Python
python3 -m http.server 3000

# Using Node / npx
npx serve -l 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
